# Working in the app

## Opening where you left off

The app opens the vault and the place it was showing when it was last used — the template and its tab. If that vault can no longer be opened (moved, or a share out of reach), it starts from the first screen. A vault opened for the first time shows the first template that has documents. Where the app was is kept in its settings on this device, never in the vault.

## Keyboard

| Keys | What they do |
|---|---|
| Ctrl+S (⌘S) | Saves what is being edited — a document or a template — from any field, or with focus on the page itself |
| Ctrl+N | Starts a new document of the template shown, from any of its tabs |
| Ctrl+F | Goes to the box that finds the template's documents |
| Ctrl+Enter | Saves the open document and opens the next one with a judgment field still empty |
| ↑ ↓ Home End | Move along the list of documents, which is one stop for Tab; Enter opens the document |
| Ctrl+/ | Shows these keys, and hides them again; so does Shortcuts at the foot of the sidebar |

While a dialog or the list of keys is open the other keys do nothing: the question on screen is answered first. A suggested value is a button beside its field: Tab reaches it and Enter takes it, and focus goes back to the field.

## Narrow windows

A template's documents are laid out in three columns: the sidebar, the list of documents (as wide as the sidebar), and the document picked in it. The list and the document scroll on their own. A new document puts the cursor in its first field, and saving leaves it in the field being written. Picking the document already open leaves it as it is, edits and all. A document picked is read before it shows — on a network share that can take a moment — and meanwhile the one shown takes no input; the one picked last is the one that opens.

From 1024 pixels wide the toolbar button folds the sidebar to a narrow rail and back. Below that the sidebar is a drawer over the content. It starts closed; the toolbar button opens it, and picking a place (the one already shown included), clicking outside it or Escape closes it. There the list and the document take turns: picking a document shows it in place of the list, and a button above it returns to the list.

## Unsaved edits

Unsaved edits are never dropped without asking: opening something else, switching views, opening another vault or closing the window asks first.
